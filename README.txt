Sports Blog

A simple responsive sports blog starter built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — homepage
- `article.html` — article layout/example article
- `styles.css` — all styling and responsive design
- `script.js` — mobile menu, story filter, newsletter demo, and share buttons

## Run locally

Open `index.html` in a web browser. No server or build tools are required.

## Customize

1. Change the site name and text in `index.html` and `article.html`.
2. Replace the sample articles with your own.
3. Replace the CSS gradient image placeholders with real sports images.
4. Update the author name and dates.
5. Connect the newsletter form to an email service before using it publicly.
6. Add additional article HTML pages as you publish.

## Important

The newsletter is currently a front-end demo; it does not actually collect or store email addresses.
